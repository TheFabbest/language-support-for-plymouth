# Changelog

All notable changes to the Plymouth Language Support extension will be documented in this file.
The date format is YYYY-MM-DD.

## [0.2.0] - 2026-10-10

- Added syntax highlighting for Plymouth built-in functions in their namespaces.
- Added support for `Math` built-in functions.
- Corrected highlighting for `Image`, `Window`, and `Plymouth` built-in functions.
- Removed incorrect highlighting for `false` and `true` keywords.

## [0.1.0] - 2026-07-01

First release.
